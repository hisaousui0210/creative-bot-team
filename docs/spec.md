# 要求と受入条件

## 目的

会話と直接操作を組み合わせ、個人の制作判断を次の編集へ引き継ぐWeb制作環境を作る。

## 最初の範囲

- 枠・文章・ボタン・アイコンの編集、保存、Undo/Redo。
- 要求を原文根拠付き候補として抽出するExtractor。
- 参謀2役による検討とProducerの採否記録。
- SQLiteでの候補・有効メモリ・訂正・撤回の管理。
- 版を固定した作品変更と、実行結果の記録。

## 受入条件

1. 「トップを軽快にして」から要求、レビュー、判断、変更、確認結果を一件追える。
2. 「軽快に」を「白い背景が恒久的に好き」へ一般化しない。
3. 話者と原文引用が一致しない候補を昇格できない。
4. 今回の指示を本人全体へ自動拡張せず、訂正した古い記憶を次の検索から外す。
5. 同じ要求の再送を二重適用せず、古いrevisionで現在の作品を上書きしない。
6. mockと実接続、シミュレーションと実行結果を区別する。

現在は仕様と構成だけであり、これらの受入条件を実装・達成した状態ではない。
