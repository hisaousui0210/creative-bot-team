# 段階的な実装計画

1. Dockerで起動する編集・保存・Undo/Redo・revisionの土台を作る。
2. 人工会話でExtractorのJSON契約と根拠検証を通す。
3. 参謀レビュー、Producerの採否、SQLiteの有効化と失効を実装する。
4. 実際の担当セッションから成果物を回収し、一件の要求を最後まで通す。
5. 利用可能な公式手段を確認して、アプリ入力とBot実行を接続する。
6. 再開・取消・訂正を実装し、継続利用のフィードバックで改善する。

初期デモはローカルで扱う。実機の接続方式、アカウント、予算と利用上限は導入時に確認する。最初は定期実行を入れず、小さな作業単位で進める。
