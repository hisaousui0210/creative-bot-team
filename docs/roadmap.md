# 段階的な実装計画

## M0：直接編集できるローカル画面

T-01、T-02。人工ページを4要素で表示し、編集・保存・Undo/Redo・再読込を通す。revision競合と冪等キーを先に実装する。モデルを呼ばずに制作物と編集履歴が成立することが出口。

## M1：判断を追えるmockの一往復

T-03〜T-05。人工シナリオの「トップを軽快に」を使い、Extractor、参謀、判断、Scene変更、メモリの保存・失効を追う。mockであることを画面に明示する。本人が同じ判断を検討できる実行記録が残ることが出口。固定応答を任意入力への自律判断と呼ばない。

## M2：確認済みの接続へ置換

T-06。利用可能なアカウント・公式の呼出し方式・使用量・取消・到達性を確認してAdapterを1種類追加する。実際の担当セッションのIDと成果物を保存し、mockと区別する。Devin専用の機能が必要な部分も、この工程で実在を確認する。

## M3：本人の継続利用で改善

本人の採否や訂正を次の編集へ引き継ぎ、説明の繰返しと意図違いが減るかを観測する。別分野の専門Bot、複数Botの恒常運用、一般公開はこの結果を見て別の作業として決める。

工程の日数や費用は現段階で保証しない。今回の依頼範囲は準備のみで、実装・Bot起動・モデル呼出し・定期実行・配備は行わない。
